## 已补齐的摄影工作流

- **真实处理图**：原始负片、基础转正、当前结果可切换；三阶段均由同一源图和配方在 Java 引擎生成。主预览和队列缩略图携带逐图处理配置，失败显示明确状态，不回退未经校色的图片。
- **取样与检查**：片基框选显示完整有向负片，鼠标坐标直接映射规范化源坐标，裁切/校平不会改变取样含义。真实 100% 请求完整像素，图片按自然尺寸显示并可滚动；超出预算明确拒绝，不放大低清图冒充。
- **分析**：展示引擎返回的 RGB 直方图、均值、工作范围与指定输出空间的边界样本；传感器原始剪裁统计保持不可用，避免把白平衡后的 RGB 当作传感器域。边界计数不等于已经证明丢失细节。
- **曲线**：总曲线及分通道单调曲线支持拖动、增加/删除内点、方向键与重置；每次手势独立撤销，同一拖动合并。端点受保护，键盘与鼠标使用同一配方。
- **同卷校准**：可选同卷片基与光源参考帧，绑定内容 SHA-256，服务端实际解析并检查相机/白平衡/输入空间一致性。保存校准时请求已解析的线性片基与增益，应用时展开数值并携带稳定 ID/版本；不依赖后端隐式查找前端存储。切图后的异步参考选择不会写入新图。
- **批量复用**：六组字段选择性同步，active/checked/all 范围与一次撤销不变。损坏条目、RAW/TIFF/JPEG 不兼容目标跳过，校准空间绑定随相应字段同步并在后端校验。

## 精度、色彩与导出

照片先经过 float32 线性 Rec.2020 流水线，再经过共用浮点裁切、校平、画幅放置、缩放及合成。Java2D 只生成独立 sRGB 装饰层，照片不会经过会量化的 Java2D 缩放/合成；不带框母版保留图像几何，只去掉装饰。

输出支持 sRGB JPEG、16-bit sRGB TIFF、16-bit **线性** Rec.2020 TIFF，带框与不带框均可。Rec.2020 ICC 由内置确定性定义生成：Rec.2020/D65 基色经 Bradford 适配至 ICC D50 PCS，TRC=1，与实际线性编码一致，不搜索任意系统 profile。参考 [ICC Rec.2020 登记](https://registry.color.org/rgb-registry/bt2020) 与 [ICC 适配说明](https://registry.color.org/rgb-registry/icctransform)。线性 TIFF 可无 ICC 但必须显式声明空间；有 ICC 时核验线性 TRC 和基色一致，拒绝非线性、空间不匹配或带透明度的输入。

底片导出复用受控 ExifTool 的元数据策略、暂存写入、独立回读与原子发布。源版本在队列接受、实际解码、源元数据读取和发布前核对，变化则失败且清理半成品。补充了 RAW SubIFD 元数据事实读取，避免真实 ARW 在最后写出阶段失败。输出容器位深与源传感器有效位深分别报告；预计输出不标为已核验。

底片单图导出以权威引擎结果就绪为条件，不再错误依赖普通 Canvas 图片对象；完成结果摘要与文件事实共用实际输出空间。输出 UI 隐藏冲突的普通格式/ICC/位深/固定档位控件，保留尺寸、JPEG 质量、命名和元数据；扩展名按每张图实际输出组合计算。预检以源图事实与共用几何预计输出尺寸，不分配额外全幅合成图；仅缓存有界源描述，不缓存 float 像素。

## 调度与验证入口

预览、分析与导出共用有界单槽；客户端代次淘汰过期请求，排队、原生 helper 等待与像素循环检查取消令牌；helper 结束时清理子进程和临时目录。HTTP 中止本身不等价于即时强杀所有工作，正在执行的旧代次会在下一次同客户端请求及检查点被淘汰。

- Java：`cd java-engine && mvn test`。数值/精度回归见 `FilmCompositorTest`、`FilmReferenceTest`、`FilmRequestGuardTest`、`FilmExportServiceTest`；本机真实工具与真实 ARW 回归见 `FilmExportNativeTest`、`FilmRawDecoderNativeTest`。缺少本机样片/组件时原生测试明确跳过，不能据此宣称真实 RAW 验收。
- 前端：类型检查、全量测试与构建；覆盖三阶段、100%、真实直方图/失败反馈、校准解析/版本、切图竞态、缩略图失效、曲线手势和输出一致性。
- Electron/脚本：类型检查、测试和 `pnpm test:scripts`；不调用打包命令。
- 开发环境手动链路（独立无头 Chrome/CDP；参考选择使用文件选择桥接替身，连接真实后端，不代表 OS 选择器或安装包 E2E）：合成线性 TIFF 的框选、三阶段切换、保存/应用校准、参考帧解析与宽/窄窗口；HTTP 批次实际写出三种格式，真实 Sony ARW 经完整流水线输出带 ICC 的 TIFF。文件由真实受控 ExifTool 回读核对尺寸/位深/方向/元数据。合成图只能证明链路与数值行为。

## 仍未验收或明确限制

- Gold 200 / Portra 160 的真实彩负、未曝光片基、光源/灰卡/色卡与参考成片尚无视觉/数值验收；当前仅通用彩负转换，不宣称胶卷专属还原。
- 没有内嵌 JPEG 的真实传感器 RAW、其他相机，以及 Windows/macOS x64 helper 验收仍 NOT_RUN。
- 传感器域剪裁统计、camera-rgb 阶段手工片基、跨设备校准自动换算未实现；可用片基交互明确使用 linear-working，跨空间校准拒绝套用。
- 干净机器离线安装、卸载和打包应用摄影 E2E 未运行；按用户要求推迟打包与安装验收。这不阻塞本轮源码功能补齐，也不构成正式发布支持。
