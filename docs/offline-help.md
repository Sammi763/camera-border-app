# 离线帮助

Camera Border 是本地桌面应用。导入、预览、版式编辑、EXIF 读取和导出都在本机完成，正常使用
不需要登录或网络连接；运行期不会下载 Java、ExifTool、字体或解码器。

## 第一次使用

1. 选择照片或文件夹，等待队列和当前预览出现。
2. 在“样式”中选择版式，在“摄影信息”中修改文字或应用拍摄信息预设。
3. 在“输出”中选择快速分享、标准交付或高保真归档。
4. 导出前检查显示的实际预检摘要和目标格式；单图使用“导出当前图片”，批量先勾选图片再使用“导出已选”。
5. 完成后可在导出结果中查看实际尺寸、位深、色彩空间、ICC 和元数据报告。

“当前图片”只指预览中打开的图片；“批量已选”只指复选框选中的图片。两者可以不同。

## 断网和系统依赖

可以在安装前或启动后阻断网络。应用不依赖远程服务，核心流程仍应可用。

用户不需要安装：

- Java/JRE；
- ExifTool；
- macOS/Windows HEIC 扩展；
- Node.js、pnpm、Python 或 Maven。

这些组件随安装包提供。若安装包内组件缺失或校验失败，能力探测会如实显示不可用并阻止
依赖它的导出；应用不会静默改用系统工具。

## RAW 提示

RAW 只使用文件内实际抽取的 JPEG 预览，不是真实 RAW 显影。导出报告会写明“内嵌 JPEG 预览”
以及实际像素尺寸；没有可读取内嵌 JPEG 时会失败。详见
[RAW 与保真说明](raw-and-fidelity.md)。

## 引擎状态

顶部状态栏显示本地 Java Engine 的启动、可用或失败状态。引擎不可用时，导出按钮会禁用并
显示原因；修复或重试成功后才会恢复。请不要通过安装系统 Java 来绕过安装包问题，先查看
应用日志或按[排障说明](troubleshooting.md)收集信息。
