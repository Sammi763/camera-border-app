# ADR-0005：字体随包分发、不走外网 CDN

- 状态：已接受（整理自 `java-engine/docs/FONT_CANDIDATES.md`，2025-08 文档重构）
- 权威文档：`java-engine/docs/FONT_CANDIDATES.md`（候选清单与授权核验流程）

## 背景

桌面本地应用不应在运行时依赖外网（用户可能离线；强依赖 CDN 也违背「本地优先」）。边框文字需要可信的中文（楷体/手写）与英文字体。

## 决策

- 字体文件与对应 `OFL.txt`（或 LICENSE）**随发行包分发**，运行时不请求 Google Fonts 等 CDN。
- 接入前必须逐个核验来源与授权（官方仓库/作者页面为准；无法核验一律「暂不接入」）。
- 对外暴露固定 family 别名（如 `lxgw-wenkai`），前端只引用别名，不暴露物理文件名。
- 中文字体接入前做子集化（subset）控制发行包体积。
- 渲染建立回退链：CJK → 中文字体，拉丁 → 英文字体，兜底系统 SansSerif，保证渲染不中断。

## 替代方案

- 运行时加载 Google Fonts CDN：接入最快，但离线不可用、违背本地优先，否决。
- 直接引入未经核验的第三方字体：授权风险（商用/再分发不可控），否决。

## 后果

- 发行包体积增加（子集化缓解）；每次新增字体都要走一遍授权核验流程。
- 用户离线也能获得一致的字体渲染效果。
