# 排障说明

先记录应用版本、目标平台/架构、安装包 SHA-256 和 `userData/logs/engine.log`。不要把源图、
GPS 或绝对路径粘贴到公开问题中。

## 常见问题

| 现象 | 处理 | 结果边界 |
|---|---|---|
| 引擎启动中或不可用 | 等待状态变为可用；仍失败时点击“重试”并收集日志 | 导出会保持禁用，不会生成假完成任务 |
| ExifTool/HEIC/TIFF 能力不可用 | 检查安装包是否完整、架构是否匹配、清单校验是否通过 | 对应能力显示 false；不能安装系统工具来伪造能力 |
| 导出前预检被阻断 | 阅读具体源图、格式、路径或能力原因，修正后重新导出 | 没有提交的任务不应显示 completed |
| 外部工具超时、非零退出或输出无效 | 保留日志和任务错误，清理残留临时文件后重试 | 导出失败；不能显示 SKIPPED 式成功 |
| 输出路径冲突 | 选择新目录或文件名，确认目标不存在且父目录可写 | 不覆盖源图或已有输出 |
| 只读目录、磁盘空间不足 | 换到可写且有足够空间的本地目录 | 明确失败，不把部分文件算作成功 |
| 非法路径或跨目录路径 | 使用系统文件选择器重新选择路径 | 请求拒绝，不执行越界写入 |
| RAW 没有预览 | 更换包含内嵌 JPEG 的原片，或按失败样片记录 | 不会回退到真实 RAW 显影 |
| 断网后能力消失 | 确认使用的是安装包，不是浏览器/开发模式 | 正式核心流程不应依赖网络 |

## 引擎日志

日志中应能看到 `[engine-start]` 的平台、架构、JAR、JRE 和回环地址，以及 `[engine-exit]` 的
退出码。日志中的回环端口只用于诊断，不会暴露给 Renderer 或作为用户配置。

## 提交验收证据

每个平台分别提交：安装包名与 SHA-256、安装路径、版本/commit、能力响应、E2E 日志、独立
ExifTool 输出、卸载结果和源图哈希前后对比。正式目标 macOS arm64 的证据进入发布门；macOS
x64 与 Windows x64 为候选证据，Windows 固定为 `SIMULATED`，不能互相替代；未取得原生证据时标记 `NOT_RUN`。清洁系统和操作系统断网证据必须按
[阶段 6 证据格式](stage6-evidence.md) 提供，CSP 自测不能替代真实网络阻断记录。
